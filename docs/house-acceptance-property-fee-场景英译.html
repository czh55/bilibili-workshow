✕ ✕ 直译腔：You block me from checking the house.

验房→take possession / inspect the unit。

✕ ✕ 直译腔：The property fee is paid by the developer in full amount.
✓ ✓ 地道说法：The developer pays the full property fee.

全额交纳→pay the full fee，更口语。

✕ ✕ 直译腔：Every day is 0.03%.

✕ ✕ 直译腔：I will go to the housing construction department to reflect.

反映→take this to / file a complaint。
