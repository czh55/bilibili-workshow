Questions Two and Three: Resume and Advantages

避坑 PITFALLS

✕ ✕ 直译腔：I want to change the job in March and April.
✓ ✓ 地道说法：This is the peak season, but the timing may still be wrong for me.

金三银四直译不必要，用 peak season 或直接表达时机。

✕ ✕ 直译腔：The leader is not able.
✓ ✓ 地道说法：I think my manager isn't great, but that's not a reason to leave.

「领导无能」是主观判断，英文更委婉。

✕ ✕ 直译腔：My resume is too flowery now.
✓ ✓ 地道说法：Changing jobs every year looks bad on a resume.

简历「花」是频繁更换，不是花哨。

✕ ✕ 直译腔：I should hibernate again.
✓ ✓ 地道说法：I should lie low, build up, and get stronger.

蛰伏用 lie low / build up 表达，不直译 hibernate。
