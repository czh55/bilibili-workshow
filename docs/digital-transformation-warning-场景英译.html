Rule one: if the level is too low, don't go

避坑 PITFALLS

✕ ✕ 直译腔：Reduce human / reduce labor force.
✓ ✓ 地道说法：Reduce headcount / cut down on staffing.

「减少人力」在职场语境里更常说 headcount 或 staffing，reduce human 是典型中式英语。

✕ ✕ 直译腔：Finance is a finance mouth.
✓ ✓ 地道说法：Finance uses a financial lens.

「口径」不能直译成 mouth / caliber，用 lens 或 perspective 表示看问题的角度。

✕ ✕ 直译腔：Everyone talks to himself.
✓ ✓ 地道说法：Everyone reports the numbers that flatter themselves.

「自说自话」在这里是「自己报自己好听的数」，不能按字面翻成自言自语。

✕ ✕ 直译腔：Take out a number for them.
✓ ✓ 地道说法：Pull the numbers / run a query for them.

「取个数」在数据语境下更常说 pull the numbers 或 run a query。
