关键因素：传感器尺寸

The Key Factor: Sensor Size

情境手机标F1.9、F2.8等大光圈，却拍不出相机的虚化感。关键因素是传感器的尺寸，它决定了光线的接收能力和虚化。全画幅、半画幅、Pocket3一英寸、iPhone主摄和长焦的传感器尺寸相差非常夸张。语域：摄影教学，原理分析。

等效光圈

The Equivalent Aperture

情境传感器尺寸之间存在裁切系数。把手机光圈换算成相机的等效光圈值，就能对比虚化程度。iPhone 16 Pro Max长焦：120焦段、1/3.1英寸、F2.8、裁切系数7.5，等效全画幅F21，接近相机最小光圈值，拍出刀锐奶化几乎不可能。语域：摄影教学，等效换算。
