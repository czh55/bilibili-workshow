Q1–Q2FCP 里怎么用 S-Log，以及如何查看光圈

S-Log 素材在 Final Cut Pro 里先认对色彩空间，再转换，最后才创意调色。库建议 Wide Gamut HDR，SDR 成片项目可用 Rec.709。检查器里选对应 Camera LUT（如 S-Log3 / S-Gamut3.Cine），或导入 Sony 的 SLog3SGamut3Cine_To_LC-709 类技术 LUT。元数据不准时，用色彩空间覆盖纠正。

光圈等拍摄参数写在文件元数据里：Finder 简介有时可见；更稳的是 ExifTool / MediaInfo / ffprobe。转码成片常把元数据清掉。FCP 检查器信息面板也可能显示，取决于素材是否保留相机标签。

最短后期路径（SDR）

  • 库：Wide Gamut HDR；项目：Rec.709
  • 确认拍摄为 S-Log3 + S-Gamut3.Cine
  • Camera LUT 或 Sony LC-709 技术 LUT
  • 色轮修曝光与白平衡，再加对比度

Q3Log 下是不是只调光圈快门对焦？

不完全对。全手动时 EV 通常不用；光圈、快门、对焦必须设。但 ISO 不是「不管」，而是锁在机身推荐 Base / 原生 ISO，用光圈、ND、灯光调进光量。暗了先加光或开光圈，不要狂抬 ISO；亮了用 ND，不要把 ISO 压到 Base 以下硬抠。

ISO锁 Base（a6700 约 800；必要时 2500）
ND / 白平衡几乎必备；WB 手动锁定

Q4向右曝光，和「暗部宽容度强」打架吗？

表面矛盾，其实两层事：「信息压在较暗区」讲的是 Log 编码曲线把很多码值分给暗部与中间调，原片看起来灰；「暗部宽容度强」讲的是正确曝光时，暗部细节还在文件里、还能拉。

码值多不等于欠曝也干净。欠曝等于把信号压近噪底，一提亮噪点一起上来。推荐是保高光前提下的 ETTR：先把信噪比拍好，再在后期压回；不是靠欠曝去「用」暗部余量。

表述纠偏

错误语感：Log 暗部强，所以欠曝也没事。
应改成：Log 看起来暗不代表真欠曝；暗部余量是曝光到位后的奖励。实务仍宁可靠右、保高光不炸。

Q5Log 会提高传感器物理 DR 吗？中灰质量会下降吗？

Log 不会让传感器物理动态范围变大。变高的是「传感器已经捕捉到的光，有多少能以可调色形式活进文件」：少做成品化膝点裁切、按档位更均匀分码值、常配 10bit。中灰放得更低（S-Log3 约 41% IRE）是为了给高光留档，不是把中灰光学画质打坏。

有代价的是量化：同样 bit 深要覆盖更宽光比，中间调平均台阶更稀。10bit 通常够用；8bit Log 猛拉中间调容易色带。光学清晰度与信噪比仍主要看曝光与 ISO。

Q6–Q7a6700 + 18-135 日出日落怎么设

a6700 用菜单开启 Log 拍摄（Flexible ISO），选 S-Log3 + S-Gamut3.Cine；旧机 PP8/PP9 槽位已不在。双原生大约 ISO 800 / 2500。优先 10bit（XAVC S-I 或 HS/S 10bit）。18-135 为 f/3.5–5.6，长焦端更暗，控光靠 ND，蓝调可跳 2500。

创作先定目标：剪影按天空；天空+地面保高光、地面略欠或用渐变 ND/补光；人脸为主则补脸、勿曝穿太阳。

18-135 特别提醒

不是大光圈头：日落后半段逼你上 ISO 2500 是正常的，比乱降快门好。逆光色散在长焦更明显。日出渐变天空务必 10bit。

Q8–Q11白平衡、光线剧变、多次调曝光会不会跳

a6700 的 S-Log3（XAVC）里白平衡基本烤进画面，不是 RAW 那种纯标签。关 Auto，按时间窗手动定一次并锁定；严重不准会先顶穿某一 RGB 通道。

日出日落亮度与色温剧变，会造成曝光与色彩连续性崩掉。解决：每 30–60 秒看斑马/直方图；变亮拧 ND 或收光圈保高光；变暗开光圈→减 ND→ISO 2500；按时间窗分段拍关键镜头。

多次调曝光会导致镜头间亮度跳跃。窗内求稳、跨窗才大改；大改发生在两条之间，避免一条里猛跳。后期先转 Rec.709，再对齐曝光与色温；差约一档通常可修，已炸高光或沉噪底救不回。现场追光的小跳跃是预期内，靠后期对齐，而不是全程参数死锁。

现场口令

快门锁死 / ISO 只在 800↔2500 跳
变亮：拧 ND（或收光圈），看斑马不炸
变暗：开光圈 → 减 ND → ISO 2500
WB：每个时间窗手动定一次，窗内别动
每分钟看一次直方图；关键镜头优先拍完
