避坑 PITFALLS

✕ The camera has no anti-shake at all.
✓ The body has no IBIS, but the lens supports OIS.

防抖在相机语境用 IBIS（机身防抖）/ OIS（光学防抖）比 anti-shake 更专业。

✕ It can't put in the pocket.
✓ It can't fit in a pocket.

fit in（放得进）才是「装进口袋」的正确表达；put in 是「放进去」的动作。

✕ The specs is not the main problem.
✓ Specs aren't the main issue here.

specs（参数）作主语用复数，be 动词用 are；the main issue 比 problem 更自然。

✕ This camera makes me no fever.
✓ This camera doesn't feed my gear obsession.

发烧/退烧是中文比喻，英文用 gear obsession（器材欲）或 GAS（器材购买综合症）表达。
