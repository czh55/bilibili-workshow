避坑 PITFALLS

✕ ✕ 直译腔：The answer, a search online casually will have it.
✓ ✓ 地道说法：A quick search online is all it takes.

「随便一搜就有」别逐字直译，用 it's all it takes / it's right there 更自然。

✕ ✕ 直译腔：The interviewer showed a yellow card to his integrity.
✓ ✓ 地道说法：The interviewer flagged his integrity.

「亮黄牌」是中文比喻，英文用 flag / call into question，直译 yellow card 反而出戏。

✕ ✕ 直译腔：The round cover only has one radius size.
✓ ✓ 地道说法：A round cover has just a single radius.

「半径尺寸」直接说 radius 就好，不必再加 size。

✕ ✕ 直译腔：This is a true thing.
✓ ✓ 地道说法：This actually happened / I'm not making this up.

「这是真事情」口语里常说 it actually happened，不要逐字说 a true thing。
