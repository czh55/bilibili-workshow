避坑 PITFALLS

✕ The sky is the bright of the photo.
✓ The sky is the bright part of the photo.

part 不能漏，bright 是形容词不能直接当名词

✕ Pull the right side up a little bit up.
✓ Pull the right side up a bit.

up 出现一次即可，不要重复

✕ We should to add blue.
✓ We should add blue.

should 后接动词原形，不加 to

✕ Form a S-shaped curve.
✓ Form an S-shaped curve.

S 发元音音素，冠词用 an
