避坑 PITFALLS

✕ ✕ 直译腔：This month than last month up.
✓ ✓ 地道说法：Sales were up month-over-month.

month-over-month / year-over-year 是固定商业表达。

✕ ✕ 直译腔：Remove the season factor.
✓ ✓ 地道说法：Rule out seasonal effects.

rule out 比 remove 更自然。

✕ ✕ 直译腔：Find out bright spot.
✓ ✓ 地道说法：Spot an uptrend / find a highlight.

uptrend 是商业语境更专业的词。

✕ ✕ 直译腔：Very bad data.
✓ ✓ 地道说法：Disastrous / terrible numbers.

用 disastrous 强化语气更生动。

认知转变 MINDSET SHIFTS

把烂数据当作「认错的证据」→把烂数据当作「找亮点的素材」
把指标当作「固定不变的口径」→把指标当作「可选择的叙事视角」
把「没亮点」当作汇报的终点→把「没亮点」当作继续拆解/换口径的起点
