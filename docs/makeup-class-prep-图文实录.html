底妆前准备：毛发清理 + 皮肤清洁 + 去死皮

00:41化妆第一步是把脸上的毛发清理一下。尤其是小胡子这块，如果隔着毛上粉底，会发现这块发青。顺着毛茬刮，别逆向刮伤自己。

01:06毛发处理完，拿化妆棉（或棉片）蘸化妆水，顺着皮肤纹路把毛茬、多余油脂和灰尘全擦下去。这一步是底妆前的皮肤清洁，目的是消除粉底和脸之间的「隔合」。

01:40鼻翼两边死皮特别硬的姐妹，可以把化妆棉泡点水敷一敷，泡软了再轻轻带下来；没有死皮感觉就不用敷。

  • 顺毛刮小胡子 → 避免粉底发青
  • 化妆棉蘸化妆水顺纹路擦 → 消除油脂灰尘死皮的「隔层」
  • 鼻翼死皮硬 → 湿敷泡软再带下来

补水 + 锁水：两个动作分开做

02:00清洁完后上保湿喷雾，拍一拍等完全吸收再来下一遍。鼻子这种糙糙的地方打圈揉一揉，把水揉进去。夏天保湿喷雾基本够用，摸着脸微微发软就可以了。

02:32如果喷雾没少喷、妆还是起皮，问题多半出在没锁水：水、喷雾、精华的作用是补水，而面霜、乳液的作用是锁水。只补水不锁水，水一蒸发还是干、起皮。

光补水、不锁水，左一层右一层抹完还是脸干起皮。
  • 补水：喷雾 / 水 / 精华
  • 锁水：面霜 / 乳液（秋冬或干皮尤其关键）

防晒：用「印」不用「搓」，基本不搓泥

03:18夏天防晒必不可少。粉扑上脸前先沾一沾、清掉毛毛；粉扑用水过一遍，再用海绵蘸防晒往脸上拍一拍，放心，海绵不会把防晒吃没。

04:10上防晒不用怕搓泥：找乳液压的防晒，拿粉扑「嘎嘎嘎」一印，很少搓泥。因为这个手法最大程度避免了手指在脸上搓——你不搓，它上哪搓泥去。

04:34防晒上完先别急着叠东西，等它成膜，可以拿小扇子扇一扇。

  1. 选乳液压的防晒
  2. 用粉扑/海绵往脸上「印」
  3. 等成膜后再上下一步

底妆前遮瑕：按颜色对号入座

04:40底妆前的遮瑕，按瑕疵颜色处理：发青的地方用紫色提亮，发黄也用紫色点，发红用绿色遮瑕液，把大面积的红处理一下。

05:00手法是刷子铺开 + 粉扑压实：刷子尖上一点，铺均匀，粉扑压一压，不会像高手那样这块薄那块厚。脸上剩哪儿不均匀——黑眼圈。

05:51黑眼圈别想着遮得完全看不出，几乎不可能。保证正面看基本看不见就够了。用三文鱼色，每次上脸就蘸一点点，少亮多次，基本不会卡粉。

  • 发青 / 发黄 → 紫色提亮
  • 发红 → 绿色遮瑕液
  • 黑眼圈 → 三文鱼色，少亮多次不卡粉

粉底液：第一笔落面中，由内向外过渡

07:26遮瑕完后来一层定妆喷雾，作用是把遮瑕定在脸上；它像双面胶，一边粘住遮瑕，一边把即将上的粉底液也粘住。干了成膜之后再上粉底。

07:39粉底液第一笔落在面中，这条线掌握着里脸和外脸的分界线。涂完后拿小刷子/粉扑往里拍，让所有粉底液最先落在面中——这是脸最需要摆平的地方，然后往后一点点过渡到外轮廓。

08:12外轮廓这块就是经常抹修容的地方，粉少一点、显得暗一点都没事，反而更立体。粉底液薄薄来一层，脸上颜色就对了。

外轮廓粉少一点反而更立体，因为那是修容该干活的地方。
  • 第一笔落面中 → 掌握里外脸分界线
  • 由内向外拍 → 外轮廓薄涂自然过渡
  • 遮瑕与粉底之间用定妆喷雾衔接

骨相三件套：提亮 + 修容 + 腮红

08:30粉底上完，提亮、腮红、修容是一组，都是为了塑造脸上的骨相。

08:34提亮不显亮？大概率是提亮色跟粉底没拉开差距——提亮一定要比粉底肉眼可见地白很多才行。不服贴像浮在脸上？往提亮里掺一点刚用的粉底液，会更服帖。

08:58提亮位置：面中、嘴角、下巴、鼻梁、眉骨、眼下。眼下提亮能让泪沟没那么暗，显得饱满。

10:01修容：正面看哪块最突出，就按那往下过度。鼻影要有层次，不是一条均匀的黑——颜色深的地方在鼻根两侧，其他地方都是过渡、往里收，别太猛。

11:36嘴唇下方来点阴影，显得嘴唇更翘更立体；下巴与脖子的交界线修一下，下颌线就出来了。

12:06腮红一方面提升气色，另一方面也是修容：外圈修容是黑的、里圈提亮是白的，中间这块空档用腮红衔接起来。鼻下、鼻背点一点腮红，也像阴影一样显得鼻子高。

  • 提亮：要比粉底明显更白；不服贴就掺粉底液
  • 修容：鼻影要有层次，深→过渡→收
  • 腮红：衔接外圈阴影与里圈提亮，唇色与腮红同色系

散粉定妆：眼皮一定要定

13:20提亮腮红修容上完，再来一层定妆喷雾：把刚才上的东西定住，同时借喷雾的水消化一下粉感。趁成膜空档理一下逻辑——遮瑕和粉底是统一肤色，提亮腮红修容是塑造骨相。

14:02定妆喷雾成膜后上散粉，把容易冒油、反光的地方定住。散粉可以全脸都上，也可以局部保留光泽感。

14:14眼皮上面一定要用小刷子沾粉好好定妆——不然画完眼线晕染得特别快，用啥产品都没用。

眼皮不定妆，画完眼线晕染特别快，画啥产品都没用。

眼妆：眼影刷具选对 + 眼线填睫毛根

14:30眼影刷有讲究：蓬松的刷子适合大面积铺色，打出来自然、边缘模糊不生硬；扁刺刷适合小范围加深，边缘会硬一些。深色眼尾和睫毛根部带一下，下眼皮也扫一点，眼球形状就立体了。

16:02眼线用刀锋刷，最好拿小笔杆，眼皮一抬，笔尖在睫毛根一填。新手不用翻眼皮，拿小刷子一点点往睫毛根部填就行，看起来不吓人。眼线一画完，眼睛一下就有神了。

  • 蓬松刷 → 大面积铺色，边缘自然
  • 扁刺刷 → 小范围加深（眼尾、睫毛根部）
  • 眼线：笔杆抬眼皮，填睫毛根部

睫毛 + 眉毛：窗户与窗帘

18:39眼睛是心灵的窗户，睫毛就是心灵的窗帘。夹睫毛：睫毛夹最下沿对准上眼皮边缘，卡住后眼睛稍微往上一翻，按一下再往上抬，睫毛就夹起来了。

19:12夹完上睫毛打底，相当于睫毛的「定型发胶」，让睫毛更久地立住。打底一定要从睫毛根往上刷，从根部撸上去才定型。打底完再上睫毛膏，也是从根捋。

19:55想贴假睫毛：新手最推荐免胶款，省去自己涂胶水。夹的位置离睫毛根三分之一处，整个睫毛弧度朝自己，贴在真睫毛根上。假睫毛对新手属于锦上添花，有它挺好、没有也行。

20:25眉毛：先用刷子把眉毛上的粉底带一带，不然上眉粉容易涂。眉粉颜色跟发色走，先填眉毛底下皮的色；染眉膏先拿流线刷蘸一蘸膏体再抹，是染毛不是抹皮；日常妆到这够了，想再精细就眉笔填眉毛中间那条线——眉毛的骨架。

  • 睫毛夹：边缘对上眼皮 → 上翻 → 按 → 抬
  • 睫毛打底 + 睫毛膏：一律从睫毛根往上刷
  • 假睫毛：免胶款，夹在离睫毛根 1/3 处

二次加深：化妆是层层渲染，不是一步到位

21:45眉毛整完，再补一遍修容和腮红：因为刚才上了散粉，把油光、颜色都「吃掉」了，需要用更深的颜色局部再加深。

22:21修容觉得太黑？往修容粉里混点散粉，既吸收颜色又有定妆效果。姐妹老说自己修容修得脏，试试买两个修容色：浅色大面积晕，深色局部加重，层次一下就出来了。

23:11补腮红一定要跟第一遍同色调——刚才用这个色，接下来还用这个色，差一点点没关系，但别从暖调换成紫调。粉稍微打一点点就够了。

化妆不是夸一下一步到位，而是头一遍来一点、再加深一点，一层层渲染。

提亮层次：大圈套小圈，再套迷你圈

24:00提亮粉有讲究。自然白那种：适合大面积，铺面中、额头、下巴。死白那种：只适合小范围单点提亮，千万不能大面积涂——涂完跟没涂一样。

24:50珠光提亮：在大面积和小面积提亮的基础上，再小小面积点两个点，比如鼻头，让它自然有亮光。

25:20三种提亮的关系就像大圈套小圈、再套迷你圈：自然白做大圈，死白做小圈，珠光做迷你圈，局部点上，提亮才有层次。

  • 自然白 → 大面积：面中、额头、下巴
  • 死白 → 小范围单点，不能大面积
  • 珠光 → 迷你圈：鼻头等发光点

口红收官：唇线笔 = 嘴唇修容

25:43到这儿开始画口红。唇线笔的作用就是嘴唇修容：先拿纸片把笔上那层蜡抹掉，不然不上色。上嘴唇薄的姐妹特别适合——把明显的唇缘分界线整模糊，看不清上嘴唇从哪开始，有扩唇效果。下嘴唇抹一下，唇更翘。

26:35口红全唇填完还觉得没血色、像生病？再拿一个比它红一点的颜色，不全唇抹，几乎只抹在嘴唇里面——大盘套小圈，颜色就有了。整体到这儿，这个小妆就完成了。

口红没血色，就拿更红的色在唇内叠涂：大盘套小圈，颜色就有了。
