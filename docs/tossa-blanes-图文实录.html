悬崖花园的三大自然机制

01:00那这是怎么做到的呢？首先，这里是悬崖，下雨后雨水顺着斜坡快速流走，不容易积在土壤里，虽然土壤偏干，但悬崖下面就是地中海，海风带着湿润的空气，让喜湿的热带雨林植物也能生长。

01:15其次，这里的岩石在白天吸收太阳的能量，慢慢释放出来，形成一个天然的温室。

01:25最后，植物园背后的山坡、树林和石墙会削弱强风，避免植物被吹折或者吹干。

  • 悬崖斜坡 → 雨水快速流走，土壤不积水（适合仙人掌）
  • 悬崖下地中海 → 海风带来湿润空气（满足喜湿植物）
  • 岩石白天吸热夜间释放 → 天然温室
  • 山坡树林+石墙 → 削弱强风，防止吹折吹干

01:50中世纪时北非海盗特别猖狂，总来加泰罗尼亚海岸烧杀抢掠，所以这里的人民才建这样的防御海堡。每次看到军事防御的地方，他们就搞几个假大炮放在这里，模拟以前在这里打海盗。
