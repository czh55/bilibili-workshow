避坑 PITFALLS

✕ ✕ 直译腔：Walking is a task for me now.
✓ ✓ 地道说法：Walking has become a daily task — I clock up ten thousand steps.

clock up 表达「累计步数」更口语。

✕ ✕ 直译腔：I can't fight anymore.
✓ ✓ 地道说法：I can't keep it up anymore.

keep it up 表达「撑不住、维持不了」。

✕ ✕ 直译腔：Life stage is not the same as before.
✓ ✓ 地道说法：My life phase has shifted.

phase has shifted 更简洁自然。

✕ ✕ 直译腔：I can take off a little now.
✓ ✓ 地道说法：I can finally step back a bit.

step back 表达「抽身、跳脱」。
