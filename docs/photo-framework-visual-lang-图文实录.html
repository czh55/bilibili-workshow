00:00—00:56

先把系列立住：一期只讲一个视觉模式

开场没有立刻拆招，而是先声明立场：对摄影爱好者来说，理解并能运用“视觉语言”是最重要的能力之一。讲述者把整套内容做成系列——每一期只讲一个视觉模式：它是什么、为什么值得用、如何在现场发现，再配上自己的案例和练习方法。

原声：“在每一期视频中，我们都会专门讲解一个视觉模式；每一次只讨论一个具体的模式。”

说明：完整转录区保留 Whisper 原文；文中偶见“视影/单读/学道”等识别误差，叙事按可见字幕与语境校正。

00:56—02:00

用英语类比：词 → 句 → 段，对应视觉模式

正式进入框架之前，视频先复习基础：视觉语言很像日常语言。单词各有含义，组合后形成句子，句子意义往往大于单词相加；段落、章节再组成故事。摄影也一样——照片里的段落、句子，最终都由最基本的视觉元素构成，而这些元素就是“视觉模式”。

原声：“而这些最基本的视觉元素，就是我定义为视觉模式的东西。”
02:00—05:00

别把模式叫成规则：互补色例子说清“改变意味着什么”

讲述者特意纠正一个流行说法：“规则就是用来打破的”。他认为“规则”一词会暗示最终该被违反；而视觉模式描述的是现实世界里可观察的视觉关系。互补色是例子：蓝与橙位于色轮相对位置，形成对比；若换成绿与橙，关系变了，照片传达的信息也会不同。因此关键不是“打破”，而是知道自己改动了什么、意义会如何变化。

原声：“你必须理解自己正在使用的视觉模式，知道什么时候使用，为什么使用，以及改变它之后会产生什么影响。”

系列目标也被说清楚：不断积累视觉模式并把它们组合起来，像造句一样形成更丰富的信息；最终希望能在街头凭直觉发现模式，并理解“为什么自己喜欢某个画面”。

05:00—06:21

本期视觉模式：框架——把主体围起来

铺垫结束后，本期主题亮出：框架。定义很直接——用一个或多个视觉元素把主体包围起来，形成视觉上的框架关系。它的首要作用是把观众注意力引向更重要的主体，提升主体视觉层级；此外还可移除干扰、制造对称与平衡、增加兴趣、引导视线。

原声：“框架其实非常简单，它指的是利用一个或者多个视觉元素，将主体包围起来，形成一种视觉上的框架关系。”

讲述者强调框架无处不在：门、冰箱开口、车窗都是天然框架；学会找框架会改变观察世界的方式。随后进入 Lightroom，用自己的照片拆解用法与关键点。

06:21—07:37

照片边缘是最大框架；窗口是次级框架；还要看比例

第一张案例用剪影人物站在落地窗前的城市黄昏：照片四边本身就是最大框架，主体落在中央；更进一步，中央窗口再次包围主体——讲述者称之为“刺激框架”（语境上更接近“次级框架 / 框中框”）。同时引入“比例”：人物在水平与垂直方向都居中，带来平衡与和谐。结论：有框架还不够，还要看主体位置、空间分布与比例是否舒服。

07:37—13:41

从樱花前景到飞机窗：一串框架用法现场走读

接下来的案例不再只证明“有框”，而是演示框架能做什么、比例如何落地。

樱花/灌木前景：讲述者站在灌木后拍摄，前景虚化植物形成自然框架，把主体围在中央并增加空间感与设计感，而不只是记录场景。

车站结构：朋友坐在由车站梁柱与屋顶形成的框架正中央，左右平衡；字幕可见“她坐的位置……”。讲述者强调：有意识使用框架并考虑比例的人，画面往往更稳；尤其次级框架里，主体位置决定和谐感。

三角框人像：只需左右或上下微调机位，就能让面部落入三角框架，眼睛落在三角中心——框架与比例一起产生协调。

主框架里的手臂边距：后期可加强框架感，但更关键的是主体与框边的空间是否左右接近；同样逻辑也用在自然框架里的海洋生物（Whisper 记为“摇鱼”，语境应为水中主体），等待它与框边距离平衡再按快门。

多层建筑框与佛像白底：建筑外围形成大框架，窗口再框住头部；佛像则用大片白色区域强烈框住头部，并同时对齐水平/垂直中心线。

飞机窗与富士山：讲述者拍了放大版与含窗框版，明确更喜欢后者——窗框提供视觉入口，告诉观众该看哪里。

建筑摄影：首尔 DDP 用三角结构框住底部小人；台北 101 则宁可多花时间找额外框架，让名建筑通过前景枝叶/结构呈现，从而增加环境叙事——观众会想“这是在哪里拍的”。

最后一个朋友人像再次叠用主框架与细微比例：门与背景结构成框，人物位置、视线方向与留白都被有意识安排。提醒收束为：不要只看到“这里有一个框”，还要问主体与框架的关系是否平衡、比例是否舒服。

13:41—14:31

练习题：只拍带框架的照片

收尾回到可执行训练：框架最大优点是无处不在——窗户、门、家具、建筑、人与环境关系，甚至你此刻坐着的位置都可能找到几个。练习时自问：主框架还是次级框架？主体位置是否合理？比例与空间是否舒服？更日常的方法是：每天出门，规定自己只拍包含框架的照片。

原声：“每天出去拍摄，然后规定自己只拍摄包含框架的照片。”
