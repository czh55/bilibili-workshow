避坑 PITFALLS

✕ ✕ 直译腔：My brain had no time to react.
✓ ✓ 地道说法：My mind went blank — I couldn't react fast enough.

went blank 比 had no time 更贴切地表达「来不及」。

✕ ✕ 直译腔：I need the touch of bodies.
✓ ✓ 地道说法：I found myself craving physical contact.

craving physical contact 更地道。

✕ ✕ 直译腔：I want to grasp a thing.
✓ ✓ 地道说法：I just wanted to grab onto something.

grab onto something 表达「抓住点什么」。

✕ ✕ 直译腔：He looked like he became weak.
✓ ✓ 地道说法：He seemed to have gone soft.

go soft 是「变软弱」的口语说法。
